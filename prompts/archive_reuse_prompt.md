# Archive Reuse Prompt

Use Song DNA System in Archive Reuse Mode.

Task:

```text
Use existing archive records only.
Do not browse unless a record is missing essential metadata.
Find low-cost ways to create publishable assets from the given record/list.

Input archive record(s):
<RECORDS>

Output only the reuse assets requested by the user.
Do not include generic advice.
```

Possible reuse assets:

- alternate POV lyric;
- short hook clip;
- caption;
- voice-over;
- visual variant;
- duet version;
- acoustic/EDM/slowed prompt;
- posting calendar, only if explicitly requested.
