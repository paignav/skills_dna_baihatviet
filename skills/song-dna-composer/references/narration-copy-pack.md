# Narration And Copy Pack

Use this reference when the user wants video narration, article copy, podcast material, captions, or on-screen text for a music/content project.

## Goal

Create copy assets that can carry the song's story outside the lyric. These should help the user publish Reels, Shorts, Facebook posts, YouTube descriptions, podcast intros, or voice-over videos.

## Components

Provide only the formats that match the user's request. For a full production pack, include:

- **Cold open:** one sharp line for the first three seconds.
- **Short voice-over:** 10-20 seconds for Reels/Shorts.
- **Long voice-over:** 30-60 seconds for deeper videos.
- **On-screen text:** 3-7 short lines that can appear instead of lyric subtitles.
- **Caption short:** one compact social caption.
- **Caption long:** a more atmospheric post or YouTube/Facebook description.
- **Podcast intro:** 20-40 seconds to introduce the topic or song.
- **Podcast one-minute script:** a concise narrated story with beginning, turn, and landing.
- **CTA:** optional, soft, and not salesy.

## Writing Rules

- Do not make on-screen text a lyric dump.
- Keep each on-screen line short enough to read in one glance.
- Use the song's central image and emotional promise.
- Avoid metadata language such as "this song is about..." unless writing a factual description.
- Voice-over should sound spoken, not like a prompt.
- Podcast copy may be more reflective, but still needs rhythm and a clear emotional turn.
- Do not invent factual backstory; if the narration uses a sourced reference, preserve confidence labels.
