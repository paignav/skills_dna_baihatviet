# Data Folder

This folder is the central working archive.

All AI agents should save persistent records here, not beside random prompts or in separate download folders.

## Folders

- `sources/`: source DNA records.
- `productions/`: generated song/content production packs.
- `logs/`: ingestion logs, duplicate skips, and run summaries.
- `indexes/`: lookup and duplicate-detection indexes.
- `inbox/`: rough source lists, raw notes, or URLs waiting to be processed.
- `archive/`: old records, retired versions, or manual backups.
